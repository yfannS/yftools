# md2html 后端接口测试文档

> 基础地址：`http://localhost:8000`
>
> 认证方式：Bearer Token（JWT），在需要认证的接口 Header 中添加 `Authorization: Bearer <token>`

---

## 接口总览

| # | 方法 | 路径 | 认证 | 说明 |
|---|------|------|:----:|------|
| 1 | GET | `/api/health` | ❌ | 健康检查 |
| 2 | POST | `/api/auth/register` | ❌ | 用户注册 |
| 3 | POST | `/api/auth/login` | ❌ | 用户登录 |
| 4 | GET | `/api/auth/profile` | ✅ | 获取用户信息 |
| 5 | POST | `/api/tools/md2html/convert` | ❌ | Markdown 转 HTML（服务端） |
| 6 | POST | `/api/tools/md2html/history` | ✅ | 保存转换记录 |
| 7 | GET | `/api/tools/md2html/history` | ✅ | 获取历史记录列表（轻量） |
| 8 | GET | `/api/tools/md2html/history/:id` | ✅ | 获取历史记录详情 |
| 9 | DELETE | `/api/tools/md2html/history/:id` | ✅ | 软删除历史记录 |
| 10 | GET | `/api/tools/md2html/themes` | ❌ | 获取主题列表 |

## 1. 健康检查

检查服务是否正常运行。

```
GET /api/health
```

### 请求示例

```bash
curl http://localhost:8000/api/health
```

### 响应示例

```json
{
  "status": "ok",
  "message": "md2html service is running"
}
```

## 2. 用户注册

注册新用户。

```
POST /api/auth/register
```

### 请求体

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|:----:|------|------|
| username | string | ✅ | 3-128 字符 | 用户名 |
| password | string | ✅ | 最少 6 字符 | 密码 |

### 请求示例

```bash
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "password": "test123456"
  }'
```

### 成功响应

```json
{
  "success": true,
  "message": "注册成功"
}
```

### 失败响应

```json
{
  "success": false,
  "message": "用户名已存在"
}
```

```json
{
  "success": false,
  "message": "参数错误: ..."
}
```

## 3. 用户登录

用户登录获取 JWT Token。

```
POST /api/auth/login
```

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| username | string | ✅ | 用户名 |
| password | string | ✅ | 密码 |

### 请求示例

```bash
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "password": "test123456"
  }'
```

### 成功响应

```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "username": "testuser"
  }
}
```

> 🔑 后续需认证的接口都需要在 Header 中携带此 token：
> `Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`

### 失败响应

```json
{
  "success": false,
  "message": "用户名或密码错误"
}
```

## 4. 获取用户信息

获取当前登录用户的信息。

```
GET /api/auth/profile
```

### 请求头

| Header | 值 | 必填 |
|--------|-----|:----:|
| Authorization | Bearer \<token\> | ✅ |

### 请求示例

```bash
curl http://localhost:8000/api/auth/profile \
  -H "Authorization: Bearer <your-token>"
```

### 成功响应

```json
{
  "success": true,
  "data": {
    "id": 1,
    "username": "testuser",
    "created_at": "2026-06-06T15:30:00+08:00"
  }
}
```

### 未认证响应

```json
{
  "success": false,
  "message": "未登录或 Token 已过期"
}
```

## 5. Markdown 转 HTML（服务端）

将 Markdown 文本转换为 HTML。此接口为兼容能力，前端优先使用本地渲染。

```
POST /api/tools/md2html/convert
```

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| markdown | string | ✅ | Markdown 原文 |
| theme | string | ❌ | 主题 ID，默认 `default` |

### 请求示例

```bash
curl -X POST http://localhost:8000/api/tools/md2html/convert \
  -H "Content-Type: application/json" \
  -d '{
    "markdown": "# Hello World\n\nThis is a **test** paragraph.\n\n- Item 1\n- Item 2\n\n```go\nfmt.Println(\"Hello\")\n```"
  }'
```

### 成功响应

```json
{
  "success": true,
  "data": {
    "html": "<h1>Hello World</h1>\n<p>This is a <strong>test</strong> paragraph.</p>\n<ul>\n<li>Item 1</li>\n<li>Item 2</li>\n</ul>\n<pre><code class=\"language-go\">fmt.Println(&quot;Hello&quot;)\n</code></pre>\n",
    "formatted": "<h1>Hello World</h1>\n<p>This is a <strong>test</strong> paragraph.</p>\n<ul>\n<li>Item 1</li>\n<li>Item 2</li>\n</ul>\n<pre><code class=\"language-go\">fmt.Println(&quot;Hello&quot;)\n</code></pre>\n"
  }
}
```

## 6. 保存转换记录

前端每次 Markdown 转换后调用此接口保存原始内容。后端自动从 Markdown 中提取标题并计算字符数。

```
POST /api/tools/md2html/history
```

### 请求头

| Header | 值 | 必填 |
|--------|-----|:----:|
| Authorization | Bearer \<token\> | ✅ |

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| markdown | string | ✅ | Markdown 原文 |
| html | string | ❌ | 转换后的 HTML（可选，前端本地渲染时可不传） |
| theme | string | ❌ | 使用的主题 ID，默认 `default` |

### 请求示例

```bash
curl -X POST http://localhost:8000/api/tools/md2html/history \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <your-token>" \
  -d '{
    "markdown": "# 我的文档\n\n这是一段测试文本。\n\n## 第二节\n\n更多内容...",
    "theme": "default"
  }'
```

### 成功响应

```json
{
  "success": true,
  "message": "保存成功",
  "data": {
    "id": 1
  }
}
```

> 💡 **自动去重机制**：同一用户 + 相同标题 + 5 分钟内的重复保存会更新已有记录而非新增。

> 💡 **标题自动提取规则**：H1 → H2 → H3 → … → H6 → 第一个非空行 → "未命名文档"

## 7. 获取历史记录列表（轻量）

返回当前用户的历史记录列表，**不包含 markdown 和 html 大字段**，仅返回标题等摘要信息用于列表展示。

```
GET /api/tools/md2html/history
```

### 请求头

| Header | 值 | 必填 |
|--------|-----|:----:|
| Authorization | Bearer \<token\> | ✅ |

### 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| page | int | ❌ | 1 | 页码 |
| pageSize | int | ❌ | 20 | 每页数量（最大 100） |

### 请求示例

```bash
curl "http://localhost:8000/api/tools/md2html/history?page=1&pageSize=10" \
  -H "Authorization: Bearer <your-token>"
```

```json
{
  "success": true,
  "data": {
    "data": [
      {
        "id": 1,
        "title": "我的文档",
        "char_count": 156,
        "theme": "default",
        "created_at": "2026-06-06T15:30:00+08:00",
        "updated_at": "2026-06-06T15:30:00+08:00"
      },
      {
        "id": 2,
        "title": "项目说明",
        "char_count": 2048,
        "theme": "dark",
        "created_at": "2026-06-06T14:20:00+08:00",
        "updated_at": "2026-06-06T14:25:00+08:00"
```

## 8. 获取历史记录详情

根据 ID 获取完整的历史记录内容（包含完整 Markdown 原文）。

```
GET /api/tools/md2html/history/:id
```

### 请求头

| Header | 值 | 必填 |
|--------|-----|:----:|
| Authorization | Bearer \<token\> | ✅ |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| id | int | ✅ | 记录 ID |

### 请求示例

```bash
curl http://localhost:8000/api/tools/md2html/history/1 \
  -H "Authorization: Bearer <your-token>"
```

### 成功响应

```json
{
  "success": true,
  "data": {
    "id": 1,
    "title": "我的文档",
    "markdown": "# 我的文档\n\n这是一段测试文本。\n\n## 第二节\n\n更多内容...",
    "char_count": 156,
    "theme": "default",
    "created_at": "2026-06-06T15:30:00+08:00",
    "updated_at": "2026-06-06T15:30:00+08:00"
  }
}
```

> 💡 如果记录包含 `html` 字段则也会返回（前端本地渲染保存时不会存 html）。

### 失败响应（记录不存在或无权访问）

```json
{
  "success": false,
  "message": "记录不存在"
}
```

## 9. 软删除历史记录

软删除指定 ID 的历史记录（只能删除自己的记录）。删除后记录不会被物理删除，而是标记为已删除（`is_delete = 1`），后续查询自动过滤已删除记录。

```
DELETE /api/tools/md2html/history/:id
```

### 请求头

| Header | 值 | 必填 |
|--------|-----|:----:|
| Authorization | Bearer \<token\> | ✅ |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| id | int | ✅ | 记录 ID |

### 请求示例

```bash
curl -X DELETE http://localhost:8000/api/tools/md2html/history/1 \
  -H "Authorization: Bearer <your-token>"
```

### 成功响应

```json
{
  "success": true,
  "message": "删除成功"
}
```

### 失败响应

```json
{
  "success": false,
  "message": "记录不存在"
}
```

> 💡 **软删除机制**：删除操作不会物理删除记录，而是将 `is_delete` 字段设为 `1`。已软删除的记录在列表和详情查询中自动过滤，不会展示。如需恢复可由管理员手动将 `is_delete` 改回 `0`。

## 完整测试流程

以下是一个从头到尾的完整测试脚本（使用 bash + curl）：

```bash
#!/bin/bash
BASE="http://localhost:8000"

echo "========== 1. 健康检查 =========="
curl -s "$BASE/api/health" | python -m json.tool
echo -e "\n"

echo "========== 2. 注册用户 =========="
curl -s -X POST "$BASE/api/auth/register" \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"test123456"}' | python -m json.tool
echo -e "\n"

echo "========== 3. 登录获取 Token =========="
LOGIN_RESP=$(curl -s -X POST "$BASE/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"test123456"}')
echo "$LOGIN_RESP" | python -m json.tool
TOKEN=$(echo "$LOGIN_RESP" | python -c "import sys,json; print(json.load(sys.stdin)['data']['token'])")
echo "Token: $TOKEN"
echo -e "\n"

echo "========== 4. 获取用户信息 =========="
curl -s "$BASE/api/auth/profile" \
  -H "Authorization: Bearer $TOKEN" | python -m json.tool
echo -e "\n"

echo "========== 5. 服务端 Markdown 转换 =========="
curl -s -X POST "$BASE/api/tools/md2html/convert" \
  -H "Content-Type: application/json" \
  -d '{"markdown":"# Hello\n\n**Bold** text with `code`.\n\n- Item 1\n- Item 2"}' | python -m json.tool
echo -e "\n"

echo "========== 6. 保存转换记录 =========="
SAVE_RESP=$(curl -s -X POST "$BASE/api/tools/md2html/history" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"markdown":"# 测试文档\n\n这是第一段内容。\n\n## 第二章\n\n更多内容...","theme":"default"}')
echo "$SAVE_RESP" | python -m json.tool
RECORD_ID=$(echo "$SAVE_RESP" | python -c "import sys,json; print(json.load(sys.stdin)['data']['id'])")
echo "Record ID: $RECORD_ID"
echo -e "\n"

echo "========== 7. 获取历史记录列表 =========="
curl -s "$BASE/api/tools/md2html/history?page=1&pageSize=10" \
  -H "Authorization: Bearer $TOKEN" | python -m json.tool
echo -e "\n"

echo "========== 8. 获取历史记录详情 =========="
curl -s "$BASE/api/tools/md2html/history/$RECORD_ID" \
  -H "Authorization: Bearer $TOKEN" | python -m json.tool
echo -e "\n"

echo "========== 9. 获取主题列表 =========="
curl -s "$BASE/api/tools/md2html/themes" | python -m json.tool
echo -e "\n"

echo "========== 10. 删除历史记录 =========="
curl -s -X DELETE "$BASE/api/tools/md2html/history/$RECORD_ID" \
  -H "Authorization: Bearer $TOKEN" | python -m json.tool
echo -e "\n"

echo "========== 全部测试完成 =========="
```

> 💡 如果 Windows 下 `python -m json.tool` 不可用，可改用 `jq` 或直接查看原始 JSON 输出。

## 统一响应格式

所有接口遵循统一的响应结构：

### 成功响应

```json
{
  "success": true,
  "data": { ... }
}
```

或带消息：

```json
{
  "success": true,
  "message": "操作成功",
  "data": { ... }
}
```

### 失败响应

```json
{
  "success": false,
  "message": "错误描述"
}
```

### HTTP 状态码

| 状态码 | 含义 |
|:------:|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证或 Token 无效 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
