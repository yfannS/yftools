# 后端项目启动指南

## 环境要求

| 依赖 | 版本要求 | 检查命令 |
|------|---------|---------|
| Go | 1.22+ | `go version` |
| MySQL | 8.0+ | `mysql --version` |
| Git | 任意 | `git --version` |

## 第一步：配置环境变量

```bash
cd backend
cp .env.example .env
```

编辑 `.env` 文件，填入你的 MySQL 连接信息：

```env
# 服务器配置
PORT=8000
GIN_MODE=debug

# 数据库配置
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_DATABASE=md2html
MYSQL_USER=root
MYSQL_PASSWORD=你的数据库密码

# JWT 配置
JWT_SECRET=md2html-jwt-secret-2026
JWT_EXPIRE=168h
```

> ⚠️ `.env` 文件已在 `.gitignore` 中，不会被提交到仓库。

## 第二步：创建数据库

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS md2html CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

> 程序启动时会自动执行建表迁移，无需手动执行 SQL。

## 第三步：安装依赖

```bash
cd backend
go mod download
```

> 如果下载慢，设置代理：`go env -w GOPROXY=https://goproxy.cn,direct`

## 第四步：启动服务

### 方式一：直接运行（开发推荐）

```bash
cd backend
go run cmd/server/main.go
```

启动成功后会看到：

```
Database connected successfully
Server starting on :8000
```

### 方式二：编译后运行

```bash
cd backend
go build -o bin/server cmd/server/main.go
./bin/server
```

### 方式三：Docker 运行

```bash
# 在项目根目录
docker-compose up -d backend
```

## 第五步：验证服务

```bash
curl http://localhost:8000/api/health
```

预期返回：

```json
{
  "status": "ok",
  "message": "md2html service is running"
}
```

## 自动建表说明

程序首次启动时，会自动创建以下表（`CREATE TABLE IF NOT EXISTS`，幂等安全）：

| 表名 | 说明 |
|------|------|
| `users` | 用户表 |
| `md2html_conversions` | md2html 转换历史记录 |
| `tool_configs` | 工具配置表（预留） |

**建表顺序**：`users` → `md2html_conversions`（依赖 users 外键）→ `tool_configs`

## 常见问题

### Q: 启动报 `Failed to ping database`

**原因**：MySQL 未启动或连接信息错误。

**解决**：
1. 确认 MySQL 服务已启动
2. 检查 `.env` 中的 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`
3. 手动验证连接：`mysql -u root -p -h 127.0.0.1 -P 3306`

### Q: 启动报 `bind: address already in use`

**原因**：端口 8000 被占用。

**解决**：
1. 修改 `.env` 中的 `PORT` 为其他端口
2. 或杀掉占用进程：`lsof -i :8000`（macOS/Linux）、`netstat -ano | findstr :8000`（Windows）

### Q: Go 依赖下载慢

**解决**：设置国内代理

```bash
go env -w GOPROXY=https://goproxy.cn,direct
```
