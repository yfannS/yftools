# yfTools-md2html 部署文档

## 一、本地编译

### 1.1 编译后端（Windows → Linux 交叉编译）

```powershell
cd d:\goProject\md2html\backend
$env:GOOS="linux"; $env:GOARCH="amd64"; $env:CGO_ENABLED="0"; go build -ldflags="-w -s" -o bin/yftools-server ./cmd/server
```

产物：`backend/bin/yftools-server`

### 1.2 编译前端

```powershell
cd d:\goProject\md2html\webapp
npm run build
```

产物：`webapp/dist/` 目录

## 二、上传到服务器

### 2.1 服务器目录结构

```
/www/wwwroot/yftools/
├── docker-compose.yml
├── backend/
│   ├── Dockerfile
│   ├── bin/
│   │   └── yftools-server
│   └── configs/
│       └── config.yaml
└── webapp/
    ├── Dockerfile
    ├── nginx.conf
    └── dist/
        ├── index.html
        └── assets/
            └── ...
```

### 2.2 上传命令

```bash
# 先在服务器创建目录
ssh root@服务器IP "mkdir -p /www/wwwroot/yftools/backend/bin /www/wwwroot/yftools/backend/configs /www/wwwroot/yftools/webapp/dist"

# 编排文件
scp d:/goProject/md2html/docker-compose.yml root@服务器IP:/www/wwwroot/yftools/

# 后端（3个文件）
scp d:/goProject/md2html/backend/Dockerfile root@服务器IP:/www/wwwroot/yftools/backend/
scp d:/goProject/md2html/backend/bin/yftools-server root@服务器IP:/www/wwwroot/yftools/backend/bin/
scp d:/goProject/md2html/backend/configs/config.yaml root@服务器IP:/www/wwwroot/yftools/backend/configs/

# 前端（3项）
scp d:/goProject/md2html/webapp/Dockerfile root@服务器IP:/www/wwwroot/yftools/webapp/
scp d:/goProject/md2html/webapp/nginx.conf root@服务器IP:/www/wwwroot/yftools/webapp/
scp -r d:/goProject/md2html/webapp/dist root@服务器IP:/www/wwwroot/yftools/webapp/
```

## 三、服务器配置

### 3.1 修改 config.yaml

```bash
vi /www/wwwroot/yftools/backend/configs/config.yaml
```

确认内容：

```yaml
server:
  port: 8000
  mode: release

database:
  host: host.docker.internal    # 容器内访问宿主机 MySQL
  port: 3306
  name: yftools
  user: root
  password: 你的MySQL密码        # ← 改成实际密码

redis:
  host: host.docker.internal    # 容器内访问宿主机 Redis
  port: 6379

jwt:
  secret: change-me-in-production  # ← 生产环境换成强随机字符串
  expire: 168h
```

### 3.2 确保 MySQL 允许容器访问

MySQL 需监听 `0.0.0.0` 而非 `127.0.0.1`，检查 MySQL 配置：

```bash
# 查看绑定地址
grep bind-address /etc/my.cnf
# 应为 bind-address=0.0.0.0

# 确保用户有远程访问权限
mysql -u root -p
GRANT ALL PRIVILEGES ON yftools.* TO 'root'@'%' IDENTIFIED BY '你的密码';
FLUSH PRIVILEGES;
```

## 四、构建镜像并启动

```bash
cd /www/wwwroot/yftools

# 构建并启动（首次或代码更新后）
docker compose up -d --build

# 只构建不启动
docker compose build

# 只启动（镜像已存在时）
docker compose up -d
```

---

## 五、运维命令

```bash
# 查看容器状态
docker compose ps

# 查看日志
docker compose logs -f yftools-md2html-backend
docker compose logs -f yftools-md2html-frontend

# 只重启后端
docker compose up -d --build yftools-md2html-backend

# 只重启前端
docker compose up -d --build yftools-md2html-frontend

# 停止所有
docker compose down

# 停止并清除镜像
docker compose down --rmi local

# 进入容器调试
docker exec -it yftools-md2html-backend sh
docker exec -it yftools-md2html-frontend sh
```

## 七、更新部署流程

改了代码后只需：

1. 本地重新编译（后端或前端）
2. 上传对应的文件（二进制 / dist 目录）
3. 服务器执行：

```bash
cd /www/wwwroot/yftools
docker compose up -d --build
```

如果只更新了后端二进制：

```bash
scp d:/goProject/md2html/backend/bin/yftools-server root@服务器IP:/www/wwwroot/yftools/backend/bin/
ssh root@服务器IP "cd /www/wwwroot/yftools && docker compose up -d --build yftools-md2html-backend"
```

如果只更新了前端：

```bash
scp -r d:/goProject/md2html/webapp/dist root@服务器IP:/www/wwwroot/yftools/webapp/
ssh root@服务器IP "cd /www/wwwroot/yftools && docker compose up -d --build yftools-md2html-frontend"
```
